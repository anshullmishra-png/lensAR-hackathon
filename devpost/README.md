# Planning material

- `design-brief.md`: the design brief, written with the Devpost Learn `plan-lens` skill by interviewing the entrant. It records a planning conversation the team had **before** building that was not documented at the time. The file itself was written on 9 November 2026, **after** the build, and says so at the top. It was not produced before the build.
- `build-brief.md`: the hand-written brief that the Lens was actually built from (architecture, scenes, content rules, safety rules). The Lens was implemented from it with Claude Code through the CLAD plugin, Lens Studio and the Lens Studio MCP. It is not output of the skill pack.
- `video-plan.md`: shot list, voice-over and honesty checklist for the demo video.
